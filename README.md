# Maribloom HQ · virtual office

My private 3D virtual office, deployed on Railway at office.workwithmaribloom.com.

- No packages to install. Railway runs `node server.js`.
- Railway Variables: `APP_PASSWORD` (makes the office private, recommended) and `SESSION_SECRET` (long random text).
- Files: index.html (the office), login.html, server.js, package.json, icons.
- Coming later: Sage, my personal assistant (her AI key will stay in Railway Variables, never in the page).
